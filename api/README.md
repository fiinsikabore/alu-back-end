# api

Python scripts that gather data from a REST API
(https://jsonplaceholder.typicode.com) about employees and their TODO lists.

## Files

- `0-gather_data_from_an_API.py`: displays an employee's TODO list progress
  for a given employee ID.

## Usage

    ./0-gather_data_from_an_API.py 2
